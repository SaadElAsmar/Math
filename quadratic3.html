Quadratic equation with a parameter (3)

Discussion according to the real parameter m

mx² + (m + 7)x + 2m − 7 = 0(E)
  1. 1)
    Solve (E) for m = 0.

    For m = 0, (E) becomes 7x − 7 = 0 (first degree).

    x = 1

    From now on, suppose m ≠ 0.

  2. 2)
    For m ≠ 0, compute Δ, the product P and the sum S of the roots, then make the sign table of Δ, P and S.

    Here b = m + 7 is not of the form 2b', so we use Δ = b² − 4ac.

    Δ = (m + 7)² − 4m(2m − 7) = m² + 14m + 49 − 8m² + 28m

    Δ = −7m² + 42m + 49

    Roots of Δ (a trinomial in m with A = −7, B = 42, C = 49):

    D = B² − 4AC = 42² − 4(−7)(49) = 1764 + 1372 = 3136 ,  √D = 56

    m₁ = −B + √D2A = −42 + 56−14 = −1    m₂ = −B − √D2A = −42 − 56−14 = 7

    Sign of Δ: the coefficient of m² is A = −7 < 0. A trinomial has the sign of A outside its roots and the opposite sign between them:

    Δ < 0 for m < −1 or m > 7 ,   Δ > 0 for −1 < m < 7.

    P = ca = 2m − 7m    S = −ba = −(m + 7)m

    Sign of P and S: a quotient has the same sign as the product of its numerator and denominator. 2m − 7 = 0 for m = 7/2 ; −(m + 7) = 0 for m = −7 ; m = 0 is the forbidden value.

    Critical values: −7, −1, 0, 7/2, 7.

  3. 3)
    Find m so that (E) has:
    1. a)
      two distinct roots x₁ and x₂.

      m ≠ 0 and Δ > 0 ⇔ −1 < m < 7.

      m ∈ ]−1 ; 0[ ∪ ]0 ; 7[

    2. b)
      a double root. Give it.

      Δ = 0 ⇔ m = −1 or m = 7. The double root is x₀ = −b2a = −(m + 7)2m.

      m = −1 : x₀ = 3   |   m = 7 : x₀ = −1

      Check: m = −1 gives −(x − 3)² = 0, and m = 7 gives 7(x + 1)² = 0.

    3. c)
      two distinct roots of the same sign. Specify the sign.

      Conditions: Δ > 0 and P > 0. From the table:

      m ∈ ]−1 ; 0[ ∪ ]7/2 ; 7[

      Sign of the roots:

      On ]−1 ; 0[, S > 0: both roots positive.

      On ]7/2 ; 7[, S < 0: both roots negative.

    4. d)
      two distinct roots of opposite signs.

      P < 0 ⇔ 0 < m < 7/2 (then Δ > 0 automatically).

      m ∈ ]0 ; 7/2[

    5. e)
      two distinct roots satisfying:
      1. i)
        Show that (x₁ − 1)(x₂ − 1) does not depend on m.

        (x₁ − 1)(x₂ − 1) = P − S + 1 = (2m − 7) + (m + 7) + mm = 4mm

        (x₁ − 1)(x₂ − 1) = 4 for every m

      2. ii)
        (x₁ + 1)(x₂ + 1) ≥ −2.

        (x₁ + 1)(x₂ + 1) = P + S + 1 = (2m − 7) − (m + 7) + mm = 2m − 14m

        2m − 14m + 2 ≥ 0 ⇔ 4m − 14m ≥ 0 ⇔ m < 0 or m ≥ 7/2.

        With a):

        m ∈ ]−1 ; 0[ ∪ [7/2 ; 7[

      3. iii)
        1x₁ + 1x₂ < m + 1.

        We need x₁x₂ ≠ 0, so m ≠ 7/2. Then 1x₁ + 1x₂ = SP = −(m + 7)2m − 7.

        −(m + 7)2m − 7 − (m + 1) = −m − 7 − (2m² − 5m − 7)2m − 7 = −2m² + 4m2m − 7 < 0

        Numerator: −2m² + 4m with A = −2, B = 4, C = 0 ; D = 16 , √D = 4 ; roots −4 + 4−4 = 0 and −4 − 4−4 = 2. A < 0: negative outside the roots, positive between them.

        Denominator: 2m − 7 = 0 for m = 7/2.

        The quotient is negative ⇔ m ∈ ]0 ; 2[ ∪ ]7/2 ; +∞[.

        With a):

        m ∈ ]0 ; 2[ ∪ ]7/2 ; 7[

    6. f)
      two distinct roots, both greater than 1.

      Conditions: Δ > 0, (x₁ − 1)(x₂ − 1) > 0 and (x₁ − 1) + (x₂ − 1) > 0.

      By e.i), (x₁ − 1)(x₂ − 1) = 4 > 0 always.

      (x₁ − 1) + (x₂ − 1) = S − 2 = −(m + 7) − 2mm = −3m − 7m > 0 ⇔ −7/3 < m < 0.

      With a):

      m ∈ ]−1 ; 0[

  4. 4)
    Find m so that 2 is a root of (E), then find the other root.

    Replace x by 2: 4m + 2(m + 7) + 2m − 7 = 8m + 7 = 0 ⇔ m = −7/8.

    Other root: 2x₂ = P = 2(−7/8) − 7−7/8 = −35/4−7/8 = 10.

    m = −7/8 , x₂ = 5

  5. 5)
    Find m so that 0 is a root of (E), then find the other root.

    c = 2m − 7 = 0 ⇔ m = 7/2.

    Other root: x₂ = S = −(7/2 + 7)7/2 = −3.

    m = 7/2 , x₂ = −3

Remark: for m = 0 the equation is of first degree and its root is 1. This agrees with e.i): 1 is never a root when m ≠ 0, since (x₁ − 1)(x₂ − 1) = 4 ≠ 0.
